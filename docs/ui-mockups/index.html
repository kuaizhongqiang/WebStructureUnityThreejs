若量程选择过大，相对误差会被放大；若过小，则读数可能溢出。一般应选择略大于被测值的档位，并等待读数稳定后再记录。这一段用于验证段间距，注意它与上一段之间的距离明显小于行距。

十一、图标（Lucide 矢量，ISC 许可可商用）
不许用 emoji：emoji 是字体渲染的彩色位图，跨系统长得不一样，而且不跟随 currentColor（亮/暗两套主题下颜色不受控）。 图标一律用 src/icons.mjs 的 icon(name, size)，渲染成 stroke: currentColor 的 SVG，因此永远等于文字色。 数据由 src/fetch-icons.mjs 从 lucide-static@1.55.0 内联生成（零外部请求、可离线打开）；许可原文 assets/icons/LICENSE-lucide.txt。 新增图标：把名字加进 fetch-icons.mjs 的 ICONS 数组，再执行 node src/fetch-icons.mjs。

十二、说明
· 三维区域用网格底纹表示"这里是画布/视口"，不是真实渲染效果。
· 页面结构来自 docs/PAGE-WORKLIST.md（按既有同类软件实测盘点），不是凭空设计。
· 技术栈标记（Three.js / Unity）按 DEC-06 标注。
· bar 与 panel 的底统一为带色毛玻璃；毛玻璃效果需要 .board__bg 的真实背景图才看得出来。
· 背景图：assets/bg-room-dark.jpg（原图 RGB×0.5 烘焙，3840×2160/63MB → 1920×1080/123KB）。
· 亮色方案在 style.css 第 18 节；深色令牌在第 1 节、毛玻璃令牌在第 3 节上方。
· 未完成的（菜单手写版、题目样式、考核样式、Unity 侧 UI）见 TODO.md。
· 页面是生成物：改 src/pages-*.mjs 后重新执行 node docs/ui-mockups/src/render.mjs。
