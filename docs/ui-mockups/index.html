reduced-motion 具名豁免（豁免前 vs 豁免后）
菜单卡片的动画不受全局「时长压到 0.01ms」那条兜底的限定（DEC-164 / D19）—— 全局兜底是带 !important 的通配选择器，任何局部选择器都盖不过它，所以只能在同一份媒体查询里用同样带 !important 的具名选择器覆盖。豁免只给 .a5r-track 的承轴过渡（最小作用域），选择器里不得有 *。
