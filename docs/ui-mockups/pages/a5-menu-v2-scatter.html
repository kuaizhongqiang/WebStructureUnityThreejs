怎么操作 / 本页口径
鼠标：空白处拖拽平移画布，滚轮缩放，悬停放大节点，点击进入。键盘：Tab 逐节点遍历，方向键＝按编号线性下一个（散点是二维自由度、方向键没有自然语义，所以不假装二维邻接），Enter 进入；键盘落焦时画布自动回到未平移未缩放的原位，保证焦点节点一定在视野里。看形态不必拖窗口：URL 开关 ?view=list 直接进列表，?view=wide 在窄窗口下强制回散点；两个都不给时按窗口 ≤900px 自动判定（切主题时开关会跟着走）。列表里仍是同一批节点，节点内容与进入方式不变，且不出现任何连线。位置只编码类别，不编码先后与强弱。
