简介

本实验以温度传感器为对象，覆盖「认识仪器 → 理解原理 → 接线 → 仿真操作 → 测验考核」的完整链路。建议按站点线顺序逐项完成，最后在「考核」中检验掌握程度。

实验前请先确认仪器完好、连线无破损；测量时注意量程档位与被测物理量一致。若读数长时间不稳定，请检查接线是否松动，并确认加热台温度已稳定后再记录数据。
