怎么操作 / 本页口径
鼠标：滚轮或横向拖拽换居中位；悬停微抬；点击进入。键盘：Tab 逐张遍历，←/→ 移焦点（被选中的卡自动落到居中位），Enter 进入。三类反馈：悬停＝描边变主色 + 微抬；居中＝主色描边 + accent 底 + 光晕；进入＝一次短暂推进 + 顶部回执文案。位置只编码「当前在看哪张」，不编码先后与强弱。看形态不必拖窗口：URL 开关 ?view=list 直接进扁平形态，?view=wide 在窄窗口下强制回伪三维；两个都不给时按窗口 ≤900px 自动判定（切主题时开关会跟着走）。
