怎么操作 / 本页口径
鼠标：按住卡片左右拖拽转环（拖过 8px 才算拖拽，小于 6px 仍算点击）；甩一下会滑行、停手自动吸附到最近一格；鼠标移到任意卡片上，滑行会立即停下（防误触）。键盘：←/→ 或 ↑/↓ 移一格（环闭合：第 9 张再按 → 回到第 1 张），Enter 进入当前焦点卡；空格 / Home / End 有意不做（环没有"首尾"）。三类反馈：悬停 = 沿视口竖起 4px + 描边变主色（不变底色、不变大小）；选中 = 主色发丝 + 主色弱底 + 内辉光（不位移）；进入 = 一次短暂放大推进（160ms 内回落）。
本页是哪个档：与 P1 同一份代码、不换形态 —— 环仍可拖、仍可 ←/→ 移焦点、仍可进入；范围类是 .a5r-ring--static，它本身不新增任何样式，只是把「吸附 / 惯性的过渡时长」这件事做成可见的评审档位（上方开关切回默认档即可对照；不写媒体查询、不依赖系统偏好，因为评审画布改不了系统设置）。窄屏垂直环见 a5-menu-ring-narrow.html。
豁免前 vs 豁免后（时长对照）：① 豁免前（系统未开"减少动态效果"）= .a5r-card 的 transform / background / border-color / box-shadow 过渡走 --dur-page 160ms ⇒ 吸附是"平滑滑入"，三类反馈有缓动。② 豁免后（系统开"减少动态效果"）= 全局兜底 * { transition-duration: .01ms !important } 先把所有过渡压到 0.01ms，再由具名豁免 .a5r-track.a5r--motion { transition-duration: 160ms !important } 把**位移层**这一条恢复成 160ms。
如实登记一处契约内在不一致：§7.6 规定豁免选择器只能是 .a5r-track.a5r--motion（不得含 *）；但按 §4.5 做法 A 的定位模型，吸附过渡是声明在 .a5r-card 上的（.a5r-track 自身没有 transition），而全局兜底会命中卡片 ⇒ 该档下吸附实际是瞬时的（0.01ms），豁免规则存在、但不改变用户可见行为。本轮按契约字面选择器落地（保住 V-S），差异如实登记在页内说明与实现记录里，不自行改契约、不改 components.css。
口径：位置只表示当前在看哪一张，不表示先后与强弱；环的左右邻接是"观看顺序"，不是内容依赖。进度环的分母取该项目自己的启用站数（不是全局 33），合计 31。
