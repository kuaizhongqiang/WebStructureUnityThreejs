怎么操作 / 本页口径
鼠标：按住卡片上下拖拽转环（拖过 8px 才算拖拽，小于 6px 仍算点击）；甩一下会滑行、停手自动吸附到最近一格；鼠标移到任意卡片上，滑行会立即停下（防误触）。键盘：←/→ 或 ↑/↓ 移一格（环闭合：第 9 张再按 → 回到第 1 张），Enter 进入当前焦点卡；空格 / Home / End 有意不做（环没有"首尾"）。键位在两种朝向下完全相同（←/→ 保留、↑/↓ 增补，都移一格），不得按朝向分支。三类反馈：悬停 = 沿视口竖起 4px + 描边变主色（不变底色、不变大小）；选中 = 主色发丝 + 主色弱底 + 内辉光（不位移）；进入 = 一次短暂放大推进（160ms 内回落）。
与 P1 的差异只有朝向：P1 是水平环（承轴 = 横向、起伏轴 = 纵向 ×0.5）；本页默认垂直环（承轴 = 纵向、起伏轴 = 横向 ×0.35）。两条纪律：① 承轴不压缩 —— 纵向用未压缩的 d(k) = R·sin(kΔ)，只有横向起伏乘压缩系数；② touch-action 由 P1 的 pan-y 反转为 pan-x（纵向手势归环、横向归页面）。角距 24° / 卡尺寸 360×420 / 档位表 / 环心纵向 42%（= 454px）两形态全部不变；`--a5r-slot` 两形态都是 249.6px，只换轴。
口径：位置只表示当前在看哪一张，不表示先后与强弱；环的上下邻接是"观看顺序"，不是内容依赖。进度环的分母取该项目自己的启用站数（不是全局 33），合计 31。上方开关切回水平形态可与 P1 对照（只换布局、不写媒体查询、不新增样式）；减少动态效果档见 a5-menu-ring-reduced-motion.html。
