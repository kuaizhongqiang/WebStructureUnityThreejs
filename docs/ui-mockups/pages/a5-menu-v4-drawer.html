本页操作与降级口径
鼠标：悬停抽屉头微探（露出可读名称）；点击拉开到底，再点收回。可以同时拉开多格 —— 等厚让位，拉开越多其余格越挤（这是"只让位、不位移"的代价，不是位移）。
键盘：Tab = 格子顺序；Enter 开合；Escape 收回当前格。焦点环画在格子本体（抽屉头）上，且只在键盘模态出现 —— 鼠标点不出来。
视觉主体藏在内页里：--lg 进度环 + 站数 + 下一站 + 简介。静止态不显示 —— 这是本页与其它四页最大的差别，也是它静止时会退化成网格的原因。
窄屏：抽屉转竖排手风琴（.a5v4-drawer--stacked），语义不变。看形态不必拖窗口：URL 开关 ?view=list 直接进竖排；?view=wide 在窄窗口下强制回横排；两个都不给时按浏览器窗口 ≤ 900px 自动判定。切主题时开关会跟着走（?theme=dark&view=list）。
减少动态效果档：让位过渡归零，但「拉开」是状态不是动画 —— 点击仍能开合、内页仍可读（display 与 flex 的切换不受时长影响）。
