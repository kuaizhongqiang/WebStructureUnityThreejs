# 07 · 框体样式规则（本项目自持）

> 性质：**本项目采纳并必须遵守的框体规则**。落地在 `docs/ui-mockups/tokens.css` 与 `components.css`（§20）。
> 本文是这些规则的**权威描述**；代码注释与其它文档要引用规则时，**指向本文**，不要指向任何外部仓库或文件。
> 与其它文档的关系：DEC-74 规定"样式单一来源 = 拆三份"，本文只讲**规则内容**，不讲拆分方式。

## 1 描边：只有一种写法

中性描边一律 **`0.5px solid var(--border-N)`**，配 α 阶梯：

| 令牌 | 深色（α 白） | 亮色（α 冷黑） | 用途 |
|---|---|---|---|
| `--border-1` | .06 | .05 | 最轻的分隔 |
| `--border-2` | .12 | .10 | 分隔线、次级框 |
| `--border-3` | .16 | .14 | **面板 / 卡片 / 条目**（`--line-1` 别名到此） |
| `--border-4` | .20 | .20 | **控件 / 输入 / 强分隔**（`--line-2`、`--check-border` 别名到此） |

- **为什么 0.5px**：Chromium 会落成 1 物理像素，视觉上是"发丝"，比 1px 更收边；配合 α 阶梯，深浅两套主题不会一边有一边没有。
- **为什么用 α 而不是实色**：α 值随主题反转（深色用 α 白、亮色用 α 冷黑），**同一句 `border` 在两套主题都成立** —— 不必为主题各写一条，也就不会出现"亮色下框线消失"。
- **例外**：虚线提示框、语义状态色描边（成功/警告/错误/信息）允许 1px 与实色令牌。

## 2 圆角：只有 6 级，按**角色**选档

| 令牌 | 值 | 角色 |
|---|---|---|
| `--radius-xs` | 4 | 极小件：字母标、行内码 |
| `--radius-sm` | 8 | 紧凑件：缩略图、清单小图 |
| `--radius-md` | 12 | **标准控件**（按钮、输入、单选/复选外壳） |
| `--radius-lg` | 16 | 大控件（高 64 的大按钮）、提示条、分析块 |
| `--radius-xl` | 20 | 独立内容卡（卡片、网格条目、步骤提示） |
| `--radius-panel` | 28 | 主围合面：**面板、对话框、浮窗、播放器、三维视口** |

- **禁止**出现 10 / 14 / 18 / 24 这类游离字面值；药丸与正圆保持 `999px` / `50%`。
- 边到边对接的容器（贴边侧栏内的面板）**不圆角**，由外层裁剪。
- 旧令牌名 `--r-1 / --r-2 / --r-3` 保留为别名（分别指 xs / md / xl），便于老样式平滑过渡；**新代码用新名**。

## 3 浮起：`border: 0` + elevation 阴影

浮层（对话框、AI 浮窗、提示浮窗、toast、悬浮工具条、视口提示条）**不画中性 border**：

```css
box-shadow: var(--elev-panel | --elev-prominent | --elev-soft);
```

三个 elevation 的第一层都是 `0 0 0 0.5px var(--elev-stroke-color)` —— **那道发丝由阴影承担**。
因此规则是：**`--border-*` 与 elevation 阴影不得同时用**（会叠出双边框）。发丝颜色可用 `--elev-stroke-color` 重绑或关掉。

## 4 交互态：只叠一层半透明

| 令牌 | 深色 | 亮色 | 用途 |
|---|---|---|---|
| `--inter-hover` | α 白 .08 | α 冷黑 .06 | 通用 hover |
| `--inter-active` | α 白 .14 | α 冷黑 .10 | 按压 |
| `--inter-hover-accent` | α 白 .24 | α 冷黑 .14 | 强调行（可点且重要的行） |
| `--inter-hover-danger` | 红 α .15 | 红 α .05 | 危险动作 |

- **hover / 按压 / 选中 一律"在原底上叠一层"，不换底色、不改圆角、不改尺寸、不改文字色**。
  这样同一个组件在任何底色（玻璃、实底、图片之上）都成立，不必为每种底各写一套 hover 色。
- **唯一例外**：实心主按钮的 hover 换色（`--btn-primary-hover`），因为它本身就是色块。
- 选中态不另造一套颜色：与 hover 同值 + 尾部 `✓` 之类的形状标记。

## 5 键盘焦点环

```css
:focus-visible { outline: 2px solid var(--ring-color); outline-offset: 2px; }
```

- **鼠标点不出环、键盘才出**：外壳按输入模态在根元素上切 `data-input-modality`（`pointer` / `keyboard`），
  指针模态下把环置为透明。规范成果页用 `.is-focus-ring` 把环"定格"出来展示。
- **输入类控件不画环**，改为描边变主色（`border-color: var(--accent)`）。
- 令牌：`--ring-width` / `--ring-offset` / `--ring-color`。

## 6 中文排版

```css
.ui-article, .ui-dialog__body {
  line-height: 1.9;                 /* 行距 */
  text-align: justify;
  text-justify: inter-ideograph;    /* 中文两端对齐，不拉伸 */
  overflow-wrap: break-word;        /* 长英文/数字串折行不断词 */
}
.ui-article p { margin: 0; text-indent: 2em; }   /* 首行缩进两字 */
.ui-article p + p { margin-top: 0.9em; }         /* 段间距 —— 必须**小于**行距 */
```

- **段间距（0.9em）必须小于行距（1.9em）**，否则"段"读不出来。
- 首末段外边距归零（文字块嵌进卡片时不多出一截空白）。
- `text-autospace: normal`（CJK 与拉丁/数字之间自动加缝）；**代码、等宽、表格里关闭**以保列对齐。
- 缩进只加在 `<p>` 上，**不给容器加** —— 否则容器里的按钮文字会被一起缩进。

## 7 明确不做（免得以后误改）

1. **超椭圆圆角平滑**（`corner-shape: superellipse(...)`）：不做。它要求所有全圆元素配对声明，
   **做一半比不做更难看**，且属性支持面窄。因此本套不需要给药丸/正圆补配对声明。
2. **亮色表面不做"全白靠描边分层"**：教学界面是多级嵌套的文档型排版，保留"浅灰蓝 + 玻璃"的层级。
3. **字号阶梯不做整体缩放**：标题/正文比例是版式的一部分，固定。
4. **禁用态不使用"整体降低不透明度"**：禁用用**虚线框 + 锁图标 + 次级文字**，与可用按钮靠**形状**区分（不只靠明度，色弱也能分辨）。
5. **站线圆点保留 2px 描边**：它是"环"而非分隔线，不适用发丝规则。

## 8 与主题的关系

以上规则全部通过 `tokens.css` 的令牌取值，两套主题（`[data-theme]`）各给一份数值。
**改样式时不要写死数值**；要调就调令牌（例如"发丝太淡"→ 上调 `--border-3/4`，全站同时生效）。

## 9 页面底图（2026-10-15，DEC-149）

外壳**整页**铺一张展馆烘焙预览图：`web/public/bg/room-dark.jpg`（1920×1080 / 123KB，RGB×0.5 已烘焙进图）。
面板是毛玻璃 —— 底图从面板底下透出来，这是排版稿"底板 + 毛玻璃"观感的来源，**不是背景装饰**。

- **两层叠**（产品里不许用 `::after`：绝对定位层会盖到面板之上）：
  上层 = 面纱 `linear-gradient(var(--board-veil), var(--board-veil))`（深色 alpha=0 不加纱；亮色 42% 白纱把深色照片抬亮），
  下层 = `var(--bg-0)` + 照片本体（`center / cover no-repeat`，铺不满时露的是同色系底色，不留色块接缝）。
- **取值只认令牌**：面纱 `--board-veil` 来自 `tokens.css`（深浅各一份），与排版稿 `mockup-shell.css` 的 `.board__bg::after` 同一口径；
  要更暗/更亮就调令牌，不要在 `product.css` 里写第二次颜色。
- **落点**：`web/src/styles/product.css` 的 `.app-root`；换图只需替换同名文件，样式不用动。
- **评审可见**：`docs/ui-mockups/index.html` 第九节有深浅两档对照展示（硬纪律：样式成果页看不到的样式视为未完成）。
